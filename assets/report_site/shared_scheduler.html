阶段实际发现结论
胺加成CC(N)=O.CN ↔ CN[C@@](C)(N)O物理边通过，四面体进入共享前沿。

构象处理

最终调度代码以 0.5 Å 的对称感知分子 RMSD 建立构象簇，每个构象簇选择当前最低能代表构象。当前验证运行把同一初始物种识别为 {{ summary.final.initial_conformer_clusters }} 个构象簇，同时仍在 TransitionNet 中显示为一个物种节点。

证据边界

  • 所有边仍是 AIMNet2-2025 一阶鞍点与双侧下降证据，没有新增 DFT/IRC。
  • 并行改变任务完成顺序；reservation 和 seed 随机数均记录，网络写入只发生在中央进程。
  • 本轮证明了新物种会自动进入搜索前沿；没有证明完整转酰胺化路径已经闭合。
