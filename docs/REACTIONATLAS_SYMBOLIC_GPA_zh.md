# 从 ReactionAtlas 到符号引导的 GPA 式探索

核查日期：2026-09-30。本文是设计分析；本轮未下载完整数据库、安装新模型或启动新势能搜索。

## 1. 外部资源与导入决定

- [ReactionAtlas 正文与补充方法](https://arxiv.org/html/2606.30778v1)：小分子糖化学/formose 网络；生成提议与局部势能探索共同扩展网络。其模型自改进仍是后续研究方向。
- [作者代码](https://github.com/mx-e/reaction-atlas)：可参考物理工作流；公开版本不包含生产环境的云调度与网站。
- [数据发布](https://zenodo.org/records/21358136)：文件 `reaction-atlas-public-20260714.sql.gz`，页面列出 26.9 GB，MD5 `3ea2e02391a36f0ac1e8a35586f96e10`；恢复约 70 GB。发布描述包含 ML 路径和 DFT 补充计算。
- [表结构](https://reactionatlas.bifold.berlin/downloads)：需保留 compounds、minima、构象 TS、reaction TS 的层次，以及原始轨迹。
- [提议器权重位置说明](https://github.com/mx-e/reaction-atlas/blob/main/docs/data.md)：`packages/worker/models/ts_best_model`，约 10 MB；消费者为仓库中的 MoreRed 源码。
- [MD-ET](https://github.com/mx-e/md-et)：公开 ASE 接口与权重，可作为后续对照后端。

发布页之间存在差异：Zenodo 的唯一反应数为 21,150，网站为 22,315；论文 v1 还有不同快照统计。不得混合成一个确定版本。最终以下载文件校验、实际表行数、完整端点集合的去重查询为准。网站与 Zenodo 的恢复容量说明也不一致，应按较大的容量规划。

导入证据分级：

1. 原始 ML 候选及路径；
2. 在指定 ML 后端满足驻点、曲率与实际连接检查；
3. DFT 单点/梯度/Hessian；
4. DFT 优化一阶鞍点；
5. DFT 双侧 IRC 加端点极小值认证；
6. 有电子结构依据且经过审核的符号解释。

这些标签分别保存。第三、四层不能直接升级为第五、六层。暂无依据把整个发布库当成 DFT-IRC 或弯箭头真值库。

## 2. 本项目的核心对象

一个配对样本应包含完整原子体系、反应物极小值、TS、实际两个端点、路径帧、电子结构证据、一个或多个符号解释及计算层级。

符号提议 A 与事后解释 A* 分开保存。A 引导找到事件，并不使 A 自动成为该事件的正确标注。允许 A 与 A* 不同，也允许多个等价解释。

建议三个循环共享同一事件库：

```text
探索循环：已有极小值 → 符号/几何提议 → seed + 初始方向 → 鞍点 → 两侧端点 → 新极小值
解释循环：已验证事件 → 路径电子分析 → 相容箭头集合 → 审核后的配对样本
学习循环：累计事件与失败尝试 → 离线更新提议/几何/排序模型 → 留出体系评估 → 新版本
```

先完成探索与解释循环，达到预设验证标准后再更新模型。新节点加入网络与模型参数更新是不同操作。

## 3. 符号到三维种子的具体方案

### 3.1 输入与局部动作

输入 S = (Z, X_R, G_R, Q, M, 环境)，分别为原子、三维构象、图、总电荷、多重度和环境。
动作 A 是一套完整电子对重排：每支箭头记录 source、sink、电子数及原子映射。

局部模式仅实例化在体系中已存在的原子上，保留旁观基团。显式水、酸碱或催化剂必须先成为输入的一部分。原子和总电子守恒；价态合法只证明记账可行，不证明存在相应 TS。

从 A 回放得到净变键 ΔB，同时保留 A 本身。图级产品是假设，不需要真实产品的三维结构。

### 3.2 几何约束

将动作编译为局部内坐标条件：

| 符号信息 | seed 约束或采样自由度 |
|---|---|
| 成键/断键 | 相关原子距离缩短/伸长 |
| σ/π 键级变化 | 距离与局部平面性变化 |
| 质子转移 D–H → A–H | D–H、A–H 距离和 D–H–A 角 |
| 取代式进攻 | 亲核位点—中心—离去基团相对方向 |
| 羰基进攻 | 羰基两侧进攻面、接近角和扭转 |
| 环化/协同重排 | 多个变键的相对进度、构象与立体关系 |

这些是提议先验，须采样而非强制唯一几何。图中的孤对电子不包含三维轨道方向；初始可用局部几何近似，后续用 DFT 局域轨道检验。不能从原子部分电荷唯一确定电子对来源。

### 3.3 种子族，而非单个线性插值

对反应中心内坐标 q_c 设置多个进度目标 q_c*。通过 SciPy least_squares 求几何：

    L_seed(X) = ||W_c (q_c(X) - q_c*)||²
              + λ_keep ||q_keep(X) - q_keep(X_R)||²
              + λ_stereo L_stereo + λ_clash L_clash

约束残差先用各自长度/角度尺度无量纲化；角度使用周期残差。局部保持项允许旁观骨架松弛，不锁死整个分子。

多个变键允许不同进度。例如先伸长待断键，再缩短待成键；也采样相反顺序与近协同方案。不得把全部箭头强制同步当作物理规律。

可从 q_c 的 Jacobian J_c 求初始笛卡尔方向：

    d0 = argmin_d ||W_c (J_c d - Δq_c)||² + η ||d||²

去掉整体平移/转动后归一化。非线性较大时，在拟合后的 seed 处重新构建方向。输出包括 X_seed、d0、A、约束参数、随机种子与来源。

如使用受约束的短程 MLIP 松弛，只用于准备 seed；最终 TS 必须在撤除所有符号约束后求解并认证。

### 3.4 可选学习模块

第一版无需训练：局部动作 + 内坐标拟合已能连接当前 Dimer 接口。

后续学习 p(X_seed, d0 | X_R, A)，可采用等变图网络或条件生成模型。无向位移轴应允许 d0 与 -d0 等价；箭头条件和净变键条件需做消融。

另一种低成本接法：无条件几何提议器先生成若干 TS 候选，再用符号相容性排序。不能把未用箭头训练的 MoreRed 直接称作箭头条件模型；正式条件化需要模型修改和训练。

## 4. GPA 式物理层

当前仓库已实现的是 GPA 式探索流程，数值 TS 求解器为 ASE Dimer，并非完整移植原 GPA。

1. 用 seed 和初始方向进行单端鞍点搜索；没有目标产物也能启动。
2. 检查真实后端上的残余力、去刚体 Hessian、恰好一个显著负模。
3. 沿负模正反方向出发，得到两个端点；MLIP 双侧下降先记录为候选连接。
4. 检查两个端点的梯度与曲率，记录真实原子映射、构象和图。
5. 关键事件进一步 DFT TS 优化、双侧 IRC 与端点 Hessian。
6. 登记实际 B↔C；若提议源 A 不在这两个端点中，不创建 A 的虚假连接。

NEB 用在两个端点均已具备的候选路径细化或连接检查；开放式起始探索可使用 Dimer/P-RFO，不要求先运行 NEB。普通几何最小化只会趋向极小值，不能承担鞍点求解。

不同构象分别保存；同一端点对允许多个 TS。构象网络与化学转化统计分开。双分子阶段使用带化学计量的反应节点，完整记录所有组分。

## 5. 三维事件回到电子机理

先从实际端点确定净变键，再枚举守恒且可回放的箭头解释。路径上选取若干 DFT 几何点，分析键级、局域轨道/占据变化及必要的密度证据，并比较不同解释。

IBO 的轨道编号需要沿路径跟踪；旋转、轨道交换、局域化选择会影响表述。几何 TS 或负模只给核位移方向，不唯一决定电子箭头。保留多解、解释置信等级与审核记录，避免把符号提议循环标成自己的真值。

高质量样本还应覆盖意外事件与失败尝试。失败细分为几何构建失败、同谷返回、非一阶鞍点、端点不匹配、预算耗尽及 DFT 未保留等；单次失败不能标为反应不可能。

## 6. 数据和模型的实际使用顺序

1. 读取 ReactionAtlas 事件和端点，保留原始字段与版本；按原子守恒、映射、梯度、曲率、路径完整性和 DFT 层级分层。
2. 首批选择与现有 AIMNet2-rxn 范围一致的净中性、闭壳层 CHNO 系统。离子/自由基不能直接交给当前后端；中性总体内的离子对也需要针对性验证。
3. 对每个事件先生成可回放的候选箭头，再挑选代表事件补电子证据。无需等待与 FlowER 找到完整端点字符串交集。
4. 构建小规模、反应家族留出的配对集，然后做仅反应物输入的发现实验。
5. 加入 MoreRed 和 MD-ET 作为独立提议/势后端对照；同一对照内控制后端、预算和验证标准。跨后端绝对能量不可混用。

现有 AIMNet2-rxn 的域限制见[作者模型卡](https://huggingface.co/isayevlab/aimnet2-rxn)。MD-ET 的力不由能量梯度严格给出，见[作者论文](https://arxiv.org/abs/2503.01431)；若接入，需检查力—能量一致性、Hessian 对称性和实际 DFT 连接，不能仅换 calculator 后假定所有势能面算法性质保持。

## 7. 必须证明的增益

固定物理求解器及总成本，比较：几何采样、反应中心随机、净变键、完整源—汇箭头、生成模型、符号与几何混合。

两种实验分开：

- 条件恢复：给予正确动作，检验符号如何帮助找到对应事件；这是 seed 模块测试。
- 开放探索：只给予初始物种/构象和试剂条件，自行提出动作并扩展网络；报告提议、筛选与失败的全部成本。

主要指标为每单位成本新增的 DFT 认证连接、未见家族泛化、连续扩展深度、关键路径覆盖，以及独立审核的符号解释质量。随后才比较调度策略和模型更新前后收益。

优先做 20–50 个经过筛选的事件作为工程规模起点，并根据实际 DFT 成本调整；这不是已完成实验或预期成功率。保留未见分子/局部电子模式的测试集，反向事件与构象不得跨训练/测试泄漏。

当前 v2 已证明工作流可产生部分可复核连接，尚未证明完整箭头稳定优于净变键，也未实现模型自改进。详见[当前结果](../reports/validation_v2/RESULTS_zh.md)。
