# 验证 v2：符号引导的增益来自哪里？

固定方案：`configs/validation_v2.json`；独立输出：`reports/validation_v2/`。

## 问题与对照

检验位移幅度、反应中心信息、完整源—汇信息分别影响多少搜索收益，以及 MLIP 连接能否经独立 DFT/IRC 保留。

| 条件 | 可用信息 |
|---|---|
| geometry | 当前构型，局部原子对随机方向 |
| center_random | 再加反应中心原子 ID；不读取目标键级或产品图 |
| bond_edits | 再加净变键，由几何拟合生成方向 |
| arrows | 再加电子源—汇配对的进度耦合 |

所有种子的内部位移范数统一为 0.6、1.0、1.4 Å，去掉刚体平移和旋转。最终物理搜索不带提议偏置。净变键相同但源—汇不同的候选分别保留。

每种条件每起点最多 6 次搜索、每节点每批 3 种子、每次最多 1,200 次势评估、总计最多 6,000 次。实际消耗和预算截断单列；与 v1 不同，不能将两轮结果当作完全相同协议直接相加。

## 数据

- 核心：乙醛、硝基甲烷，分别使用随机种子 17、29、43。
- 扩展：SynEPD 22（乙酰胺）、1741（环丁酮），仅种子 17。
- 乙烯醇不作为独立核心体系重复计数。
- 扩展体系从公开反应物图生成 8 个 ETKDGv3 构象，经 UFF 选择收敛且最低能者；这是初始化几何，不是数据库量子几何。
- 原符号条目可能隐含环境或催化条件。本轮只检验声明的孤立中性体系，不声称复现实验条件。

## DFT 复核

在看到 DFT 结果前，从 v1 两个根连通化学图对各选一个代表：`MR_8342_1/arrows/edge0`（乙醛—乙烯醇）和 `MR_460039_0/arrows/edge1`（硝基甲烷意外连接）。

气相闭壳层 ωB97X/6-31G(d)：精修 TS、检查 Hessian、双向 Sella IRC、端点优化及检查。预期端点是实际 MLIP 结果；如 DFT 改连，保留为替代事件。仅验证物理连接，当前不生成新 IBO 标签。单重态内的路径认证不等于全局电子基态或实验机理认证。

该 DFT 方法与 AIMNet2-rxn 训练参考层级不同；此处检验连接能否保留，能垒差异包含理论层级变化，不能直接当作纯模型误差。精修前后 TS 的刚体对齐 RMSD 同时保存，避免把端点图相同等同于路径完全相同。

## 评价与运行

主要指标为累计势评估预算下的根连通化学图对。另报首次连接成本、新物种、平行 TS、继续探索、失败与未覆盖分支。先展示各随机种子，再做起点内配对比较；只有两个核心体系，不作夸大显著性结论。

```powershell
.venv-explore\Scripts\python.exe scripts/data/prepare_validation_starts.py
.venv-explore\Scripts\python.exe scripts/exploration/run_validation_campaign.py
```

结束后运行 `scripts/exploration/summarize_validation_campaign.py reports/validation_v2`。最终报告区分成功、改连、未收敛与未完成，缺失计算不作为否定证据。

## 本轮补充诊断的处理

硝基甲烷主验证未保留 MLIP 端点对，且一侧初次优化后存在约 -62 cm⁻¹ 低频虚频。额外沿该负模微扰并以更严力阈值精修，是在看到主试验结果后进行的数值诊断，不计入主协议的成功率。其原始输出、迭代轨迹、停止/续算记录和单独 Hessian 均保存；只检查了负向分支，另一方向未计算。补充结果不改写主试验判定。

主试验的事件记录与物理反馈分别输出 `DFT_events.jsonl` 和 `DFT_feedback.jsonl`，不把意外连接或失败候选转写成“原符号反应不可能”。
