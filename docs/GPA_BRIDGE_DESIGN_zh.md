# GPA、势能面与符号机理的连接方案

依据：2026-09-29 阅读 `D:/学习相关文档/LEARN/MILP/GeoTransitionAtlas-Migration` 的 README、架构说明，以及 geometry/aperture、energetics/critical、descent、stationary_points、transitions/network、calculators 等关键模块。本次未修改或运行该仓库。

核心目标是把 GPA/势能面发现的基元事件转成有电子结构证据的符号机理，并建立可双向使用的数据库。可以先用两个已有模型与计算工作流完成；重新训练通用反应生成器或势模型不是前置条件。

## 已有基础与迁移边界

GPA 项目已经包含几何通道提议、Dimer 初猜、鞍点阶数检查、双侧下降、极小值聚类和连接网络。`LocalNetwork` 使用 `MultiGraph`，能够承载同一对极小值之间的多条连接；这适合保留不同构象与路径，而不是把同端点事件全部合并。

当前 GPA 主域是周期晶体离子迁移：空间通道通常是移动离子在宿主中的三维路径。分子反应则涉及多个原子在构型空间中的协同变化。原有可达通道/孔径场不能直接当作分子反应坐标。应复用“几何提议—势能搜索—独立验证”的架构，重新设计分子构型提议。

已有 `critical.py` 支持多原子活动空间，不能把整个项目概括成只能移动单离子。不过，单离子和固定宿主前端仍有专门假设；活动子空间的一阶鞍点不自动等于无约束分子的全空间一阶鞍点。该模块全活动空间仅投影平移，分子振动分析还需要合适的转动处理。`descent.py` 中记录的 FIRE 下降轨迹不是严格 IRC。

当前计算器加载 `TensorNet-PES-MatPES-PBE-2025.2`。将流程用于分子反应时，应选择已验证覆盖目标反应域的势模型，不能因计算器同样接受 ASE Atoms 就认定原权重可直接迁移。

## 两个模型与工作流的分工

| 部分 | 作用 | 是否必须重新训练 |
|---|---|---|
| 符号模型，例如 FlowER | 提议电子重排/基元步骤，辅助约束反应端点与候选 | 可先复用现成模型 |
| GPA 思路与搜索算法 | 提议多样的几何初猜、组织候选探索和事件网络 | 属于算法与工作流设计 |
| 反应势模型，例如 AIMNet2-rxn | 为搜索提供能量与力 | 可先复用适用域内的模型 |
| 量化计算 | 同层级 TS/连接性复核，沿路径取得波函数 | 是配对证据来源 |
| 电子结构到符号的解释层 | 从轨道变化生成相容箭头集合，保留歧义 | 起步可用受约束规则与人工审核，后续研究学习模型 |

物理发现路线：几何提议 → MLIP 搜索 → TS/双侧连接验证 → 沿路径电子结构 → 符号解释 → 配对事件。

符号引导路线：符号假设 → 相容的原子映射与三维构型提议 → 同一物理搜索/验证流程 → 接受、修正或保留未解决状态。

MLIP 的能量、力和原子电荷不提供 IBO 所需的占据轨道。FlowER 也不是现成的“轨道→箭头”解码器，必须补上解释工作流。IBO 沿路径揭示电子流已有直接文献依据：[Knizia & Klein 2015](https://doi.org/10.1002/anie.201410637)；[作者说明](https://sites.psu.edu/knizia/2015/03/)。

## 数据库匹配的三个层次

1. 完整体系端点相同：寻找已有记录是否恰好描述同一化学体系，之后仍需核对原子顺序、条件和物理连接。
2. 反应中心/局部电子重排相似：检索可能适用的机理表达，允许外围取代基不同。这给出机理家族或类比候选，不能当作同一个物理事件的正配对。
3. 对选定的物理事件计算并生成符号解释：通过同一原子身份、有序路径、电子结构和审核记录，主动建立真正的跨表示配对。

此前检索只实施了第 1 层，且只比较原版 FlowER 与 RGD1 映射 CSV。零结果不能推出它们没有共同机理类型，更不能推出 RGD1 反应无法符号化。直接交集不足时，第 3 层仍然可以工作；第 2 层可为其提供表达候选和标注参考。

正式匹配不能任意去掉溶剂、反离子或其他组分。两端结构未改变的分子也可能参与催化或质子接力，需要保存完整体系并记录参与证据。

## 符号表达的边界

常见成键、断键和电子重排可以用推电子符号表达；双电子箭头与单电子鱼钩箭头应区分。[IUPAC electron pushing](https://goldbook.iupac.org/terms/view/08166/plain)

“能够画出守恒的箭头”不自动说明该箭头被所计算路径支持，更不保证表示唯一。离子迁移和构象变化也可能有 TS，却没有传统有机反应意义上的净共价键变化。数据库应允许无净键变化事件以及不同的表示类型，不强行为每条物理路径生成非空弯箭头。

建议先限定闭壳层、绝热基态、小型分子体系，研究原子一致性明确的电子对重排。若使用 AIMNet2-rxn，还需限制 CHNO、净中性适用域，并考虑其训练数据包含 RGD1 的重叠问题。[官方模型卡](https://huggingface.co/isayevlab/aimnet2-rxn)

## 首批事件的数据单位

每个具体路径实例保存：完整体系与条件、原子身份、反应物极小值、TS、产物极小值、验证层级及活动空间、有序路径、逐帧电子结构、符号解释集合及其证据来源。用独立的机理类别/符号等价类连接不同构象或路径实例。

首批验收可以直接利用数据库提供的真实事件完成物理复核和符号化，再评估 GPA 几何提议能否从端点或起始态重新找到相容事件。数据库 TS 可以用于后验比较或调试；评估盲搜索能力时，不能同时把目标 TS 当作初猜。

基础贡献可以首先是经过审核的配对数据库、解释与验证协议、以及可复现工作流。双向学习的价值随后通过额外的搜索成功率、解释一致性和计算预算实验评估，无需先承诺重训两个大模型。
