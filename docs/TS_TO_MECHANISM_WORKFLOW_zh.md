# 后续主线：现有模型、反应势与 TS 到符号机理的算法

更新日期：2026-09-29。随机森林仅保留为历史基线。本文件保留后续逆向任务方案；AIMNet2-rxn 已接入符号引导的网络探索，NRO 和其他提议模型尚未接入。当前优先验证探索与物理连接，见 [验证 v2](VALIDATION_V2_zh.md)。

研究目标：以经过指定势能面验证的基元事件为单位，从 TS 及其反应方向提取电子重排证据，生成相容的符号解释集合；再用这些解释引导三维事件预测与物理探索。GPA 提供“候选提议—势面验证—事件组织”的思想，不要求复制晶体迁移代码。

## 后续逆向任务：TS 到电子转移

TS 的静态 XYZ 不唯一确定机理。更有信息的对象是：TS 几何、指定电荷/自旋/环境、虚频模对应的核位移方向，以及电子态对此位移的响应。局部分析可以在完成整条路径的电子结构分析前提出候选；双侧连接仍用于确定端点、方向和事件身份。

检索到与此目标直接相关的工作：

- Ebisawa et al., *Natural reaction orbitals for characterizing electron transfer responsive to nuclear coordinate displacement*, PCCP 2022，[DOI](https://doi.org/10.1039/D1CP04491E)。NRO 从核位移扰动的电子响应中提取反应相关轨道。
- Nakanishi et al., *Visualizing electron flow at transition states by natural reaction orbitals*, J. Chem. Phys. 165, 104104 (2026)，[作者论文摘要](https://pubmed.ncbi.nlm.nih.gov/42708651/)，DOI 10.1063/5.0342901。摘要报告沿虚频模诱导的占据—虚轨道混合，并在代表性周环反应等例子中关联推电子描述。

本轮核对了公开摘要及早期方法来源，没有复现 2026 年论文的完整实现。NRO 不是已下载的神经网络，也不是现成的通用箭头解码器。

建议的反推链条：

```text
TS 候选
→ 在反应势上优化、检查驻点与鞍点阶数
→ 在统一 DFT 标准上复核关键候选
→ TS 虚频方向的电子响应 / NRO 特征
→ 原子、键及电子位点之间的候选对应
→ 受守恒、端点及路径证据约束的箭头集合
→ 带歧义与证据等级的事件记录
```

算法实现应遵循原文的电子响应定义。核移动时 AO 基组也移动，不能直接相减两个几何的 AO 密度矩阵并宣称得到 NRO。有限差分诊断需要坐标/基组对应与步长收敛检查；正式 NRO 应按响应方程和占据—虚轨道分解实现。虚频模的正负号任意，需要反应物端点或外部指定方向，不能由一个静态 TS 自动决定正逆反应。

局部响应也不是整条路径的唯一机理证明。对需要消除歧义的事件，补短路径或完整 IRC 的电子结构，检查局部解释是否在路径上保持相容。简并子空间仍可能有表示自由度，NRO 不能未经实验就被视为解决全部轨道歧义。

## 现有模型的分工

| 组件 | 拟采用资源 | 职责与边界 |
|---|---|---|
| 反应势 | [AIMNet2-rxn](https://huggingface.co/isayevlab/aimnet2-rxn) | 提供能量/力，驱动 Sella、Dimer、NEB/IRC。首先限 CHNO、净中性闭壳层。它本身不输出量化波函数或完整机理 |
| 符号模型 | [FlowER](https://github.com/FongMunHong/FlowER) | 提供电子重分配候选/先验，结合观察到的端点进行筛选。它不是 TS/波函数到箭头的反向解码器；生成流时间也不是物理反应时间 |
| 图到 TS 初猜 | [RitS](https://github.com/isayevlab/RitS) | 后续正向分支的候选；接受映射反应物/产物连接信息，可采样 TS 构型。作者仓库提供 checkpoint，工作目前按其预印本状态引用 |
| 已有三维端点的 TS 初猜 | [React-OT](https://github.com/deepprinciple/react-ot) | 作为已知 R/P 构象时的预训练基线；输入条件与仅给反应物的任务分开比较 |
| 电子结构证据 | 已有 PySCF + 新增 NRO/响应分析 | 给出 MLIP 无法提供的电子结构，并与现有 IBO 分析对照 |

先完成 AIMNet2-rxn 与 TS 局部响应，不必同时接入全部生成模型。正向任务再按输入条件选择 RitS 或 React-OT。MLIP 需要配合鞍点求解器，直接最小化能量不能得到所需的一阶鞍点。

RitS 官方说明 8GB 显存可在缩小 batch 后推理，推荐 16–24GB；本机尚未实测。FlowER 官方复现配置要求至少 25GB 显存，不能承诺本机 8GB 按默认配置运行。模型需要独立环境与固定代码、权重版本。

AIMNet2-rxn 的参考层级和能量标度与现有 ωB97X/6-31G(d) 计算不同。以同一个最终 DFT 标准评价候选恢复率、端点连接和误差；不直接混用跨理论层级的绝对能量。RGD1/Transition1x 可能已进入相关模型预训练，当前四个事件首先用于工程回归，不能直接作为未见反应泛化证据。

## 真正需要开发的连接算法

1. 将 TS 模态、电子响应和端点图组织成同一个原子身份下的事件表征。避免将原始轨道编号当作监督标签。
2. 从 NRO/响应与 IBO 等多种证据提出源—汇关系，再以电子数、电荷、成键变化和路径相容性约束生成多个符号解释。NRO 轨道对不应机械地一一对应到一支箭头。
3. 定义等价类或集合目标，同时保留中继、协同关系和原始证据。本次观察后提出的原子中继收缩仅是待验证约定，不能成为通用真值生成规则。
4. 将符号假设转换为反应中心、相互作用、端点和几何提议约束，由生成模型与反应势共同探索相容的 TS。保留一定独立探索预算以发现替代事件。
5. 根据模型分歧、电子解释歧义和势模型不确定性选择补算任务。新证据分别更新势模型、符号模型或跨表示评分器，避免用一个含糊的反馈分数混合所有问题。

后续可用三维等变编码器、图/电子响应编码器、集合解码器和条件生成模型实现可学习部分；首先复用现有主干，研究必要的条件化与对应模块。模型融合应在单向与双向收益可测后进行。

## 与 GPA 思想一致的闭环

```text
模型或几何方法提出候选
→ MLIP 在明确适用域内搜索
→ 物理检查确认实际连接的事件
→ 电子响应支持符号解释
→ 保存支持、冲突、替代事件与未解决状态
→ 用新增证据改进下一轮提议与解释
```

MLIP 上成立、DFT 驻点成立、同层级 DFT 连接成立是不同证据等级。模型彼此同意不能替代独立物理检查。不同事件不应因端点图相同就强制合并，意外事件也不应被转成“原反应不可能”的标签。

## 下一阶段的具体验收

- 用现有四个已计算事件完成 AIMNet2-rxn 的能量/力接口与鞍点工作流回归，再加入未参与预训练的独立测试体系。
- 对固定 TS 比较三个信息层次：只有几何/端点、加入虚频模、加入电子响应。检验后者是否改善反应中心与电子源—汇对应，而不只复述净键变化。
- 对同一物理事件做刚体变换、原子重编号、路径采样与局域化扰动。比较原始标签、候选等价处理和响应表征的稳定性，并保留专家审核。
- 在冻结的独立测试集和同等量化预算下，比较物理搜索单独运行、符号引导以及加入电子证据反馈的方案。

已有 TS 电子流分析、TS 生成和主动学习研究分别提供了基础。新的研究贡献应通过可执行且稳定的机理反推、事件级双向对应，或更有效的物理证据获取来证明，不能仅以增加模型数量或规模作为依据。
