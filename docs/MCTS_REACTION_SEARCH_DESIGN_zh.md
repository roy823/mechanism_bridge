# 符号引导、GPA 式事件探索与 MCTS：完整设计

日期：2026-09-30。本文是下一阶段设计，不代表 MCTS、产物分布或强化学习已实现。本轮只补充文献核对与现有符号空间审计，没有启动新的势能搜索。

## 1. 目标与边界

输入：初始完整原子体系、构象、电荷/自旋、环境；若要预测实验意义的产物，还需温度、时间、浓度及催化剂/试剂条件。

输出分三层：

1. 在声明的势能面上、带实际连接证据的鞍点—极小值网络。
2. 条件于该网络与评分假设的低代价候选路径及产物候选集合。
3. 有足够自由能/速率证据后，给定时间和条件下的物种分布、主要反应通量及机理子网络。

起步范围：CHNO、净中性闭壳层、固定完整原子集合，优先单分子反应。搜索不需要目标产物；符号模块可以提出产品图假设，实际端点由物理搜索决定。原子、试剂或副产物不能在搜索过程中凭空添加或丢弃。

“完整机理”按研究范围、能量窗口与观测时间定义；有限计算不能认证所有反应空间已经穷尽。

## 3. 符号空间：操作种类有限，实例组合可能很大

有限个元素并不意味着动作空间很小。若允许每个原子和原子对作为候选位点，n 个原子有 n+n(n−1)/2 个位点；源—汇组合为 O(n⁴)，多个箭头还会组合增长。此计数只是未做化学筛选的候选上界，不是有效反应数。

应使用分层动作：反应中心 → 完整电子对重排 → 构象/接近方向 → 几何种子。先用局域性和电子记账减少候选，再由搜索按需增加动作。

### 表示

采用可回放的原子/键/非键电子表示，保留箭头集合 A 和净变化 ΔB，二者不能相互替代。一个明确的内部约定可以是：

```text
B_ii = 原子 i 上的非键价电子数
B_ij = i-j 键级 (i != j, B 对称)
N_valence = sum_i B_ii + 2 sum_(i<j) B_ij
formal_charge_i = valence_electrons_i - B_ii - sum_(j!=i) B_ij
```

该约定必须与所用 FlowER 版本的单位、隐式氢、原子顺序做显式转换，不能假定不同库矩阵约定一致。芳香图需指定整数 Lewis/Kekulé 表示并处理等价表达；纯共振变化通常不创建物理反应边。

初版只允许两电子动作：非键位点→键、键→非键位点、键→键的组合。一个物理动作是一套完整重排，不能把一支箭头当成必然存在的中间体。建议先限定 1–3 支箭头、4–8 个活动原子；这是工程起点而非完整化学边界。

检查非负占据、显式氢、总原子与总电子、电荷、自旋域及端点价态。守恒证明语法合法，不证明动力学可行。

### 动作来源

1. SynEPD/FlowER 的常见局部模式先验。
2. 受约束的局部电子对动作枚举，用于覆盖先验未见的情况。
3. 后续可接 FlowER 采样。若没有易用的精确似然，用多次采样的频率或单独评分器建立经验先验，不能把 flow matching 输出直接叫规范化动作概率。
4. 为弱先验动作保留显式探索概率，避免模型从未提议的反应永久消失。

当前精确全反应物匹配必须逐步扩展为保留旁观原子的局部模式实例化。局部模板也不能偷偷补酸、碱、质子或催化剂。

## 4. 三种对象分开保存

### 物理状态

```text
State = 完整原子集合 + 图/形式电子状态 + 构象极小值
        + 总电荷/自旋 + 环境 + 势能面/模型版本
```

同一 SMILES 的不同构象先分开。物种级合并只在需要展示或有快速构象平衡依据时进行。去重使用图、立体信息、适当原子置换、proper-rotation RMSD 和能量/曲率证据。

### 符号动作与计算尝试

```text
SymbolAction: source_state, arrow_set, delta_B, active_atoms, prior, provenance
Attempt: action_id, seed_geometry, initial_mode, random_seed, solver,
         numerical_settings, cost, failure_reason, observed_event_ids
```

同一动作允许多个种子、多个物理结果。尝试频率反映算法搜索行为，不是化学反应概率。

### 已观察事件

```text
Event: actual_left_minimum, TS, actual_right_minimum,
       forward/reverse barriers, negative mode, descent/IRC evidence,
       electronic evidence, symbolic explanations, method and uncertainty
```

若从 A 提出的种子找到 B↔C，只添加 B↔C；没有实际证据就不能添加 A↔B。该事件可保留，但只有实际连入根分量后才能参与根出发的产品路径。

同一对极小值保留多个 TS。事件图用多重图；涉及独立物种的双分子化学时，另建带化学计量的反应节点/超图，不能把任意 A+B→C 当作普通单分子边。

## 5. 几何种子与 GPA 式物理求解

箭头提供活动中心、断/成键方向及可能的协同关系；几何提供可接近方向、构象、位阻和距离。

建议从三个互补来源生成候选：

- 当前构象沿内部距离/角度坐标的小步扫描及受约束松弛。
- 多个端点假设的距离几何构造，用于产生接近鞍点的区域；不把生成产品当作已验证结果。
- 后续已有 TS 生成模型提供额外种子，作为独立提议来源。

净变键拟合、源—汇耦合和随机扰动必须保留同幅度控制。同步耦合只是初猜启发式；需要允许异步成键/断键。

物理流程：释放提议偏置 → MLIP Dimer/Sella → 残余力与 Hessian → 双侧下降 → 两端优化与曲率 → 实际图/构象登记。重要或有争议的边再做严格 IRC 与 DFT 复核。

初期探索不必依赖 NEB；已有两端或候选带后，NEB/string 可用于精修、补连和多鞍点路径拆分。找到中间极小值才拆成物理步骤，不能仅凭键变化先后拆分。

## 6. MCTS 如何驱动这个系统

### 决策树与反应网络共用数据，但不是同一对象

反应网络有回路、逆反应、汇合路径和并行 TS。初版保留 MCTS 的路径上下文树，每个树节点引用一个物理状态；物理计算通过状态/动作/设置缓存共享。

树节点记录深度、已走事件、剩余预算和访问状态。路径评分依赖前序能垒时，不可仅按 SMILES 合并 Q 值。后续才考虑严格的图上回传算法。

### 选择

可从以下 PUCT 风格分数起步：

```text
score(s,a) = Q(s,a)
           + c_prior P(a|s) sqrt(N(s)+1)/(1+N(s,a))
           - c_cost expected_cost(a)/cost_reference
```

所有项需归一化。P 可以来自合法动作的均匀分布、模式频率或 FlowER 经验先验；初版不需要价值网络。

MCTS 访问次数、实际完成的物理尝试数和动力学速率是三个不同量。缓存 rollout 不能被算作新的独立物理证据。

### 渐进扩展

使用 `expanded_actions(s) <= ceil(c_pw * (N(s)+1)^alpha)`，例如先试 `alpha=0.5`。分别限制符号动作和每个动作的构象种子；高访问分支逐渐获得更多提议。常见动作优先，保留少量合法随机动作和替代构象。

### 展开与结果接收

每次昂贵展开完成一个有预算的物理任务。可能结果：新增连接、重复连接、构象转换、实际端点不同、源节点未连接、数值未解决、超适用域。记录成本和原因；不能把数值失败当作“该反应不存在”。

若实际端点包含当前状态，则沿实际另一端扩树；若不包含，更新共享事件图但不创建假的树后继。

### Rollout 与回传

第一版用已缓存、已验证的边进行有限深度 rollout；遇到未计算的边界时停止，使用能量启发式估值。符号上想象的后继保留在假设层，不能直接进入验证网络。

同一路径内反复返回已见状态时截断这一 rollout，物理网络中的回路仍保留。标记没有未计算任务的分支，避免通过重复低能回路无限获取奖励。

新的 DFT 结果可能改连边或修正能垒。所有评分记录引用事件版本；更新后重算相关路径值，不能让旧 MLIP 低势垒永久控制搜索。初版按批次冻结网络版本，批次结束统一更新受影响统计，保留原始尝试记录。

```text
while computation_budget remains:
    select a root-reachable frontier with PUCT
    progressively sample a legal symbolic action and a seed
    reuse a matching completed attempt, or run one bounded physical job
    register the actual saddle and endpoints
    attach only physically supported successors to the search tree
    estimate a bounded rollout value using the current graph version
    back up value and cost
    periodically prioritize uncertain important edges for DFT
    update graph versions and recompute affected path/kinetic scores
```

## 7. 能量、能垒与产品评分

### 第一层：能量模型下的路径优先级

现在可以先使用电子能 E 与局部势垒 `b_e=E_TS−E_source`，但把它叫能量启发式，不能当作实验反应概率。

不要累加各步反应能来区分同一 R/P 的路径：它们会望远镜相消为总反应能。也不要把局部能垒直接相加当作总势垒。

一个可实现的近似路径代价是：

```text
B_eff(path) = E_scale * log(sum_e exp(b_e/E_scale))
```

这对应共同前因子、无逆向与无竞争路径假设下的串联等待时间对数尺度，只用于搜索排序。可配合末端相对能量构建有界 sigmoid 分数，或直接报告“B_eff—末端能量”的 Pareto 候选集合。E_scale、sigmoid 中心/宽度是搜索超参数，需要敏感性分析，不能解释为真实温度或概率。

低能产物可能隔着高势垒，低绝对 TS 能量也可能位于深井之后而难以逃逸。回路、逆反应、分支竞争强时，用下面的动力学层替代该路径近似。

初版 Q 估计路径的能量可达性；计算成本影响任务选择，新颖度只作辅助探索信号。产品排序不得把“新发现”“多访问”“模型偏好”直接当作产率。

### 第二层：网络动力学决定条件下的产品

在单分子及已说明自由能条件下：

```text
k_(i->j) = kappa * k_B*T/h * exp(-DeltaG‡_(i->j)/(R*T))
Q_ij = sum_of_parallel_channel_rates(i,j)
Q_ii = -sum_(j!=i) Q_ij
p(t) = p(0) exp(Q*t)         # row-vector convention
```

此处 DeltaG 按每摩尔能量使用，指数单位必须一致。正逆速率由同一 TS 和两端自由能计算，以保持相应平衡关系。平行通道求和，但要去除重复搜索到的同一通道及正确处理对称简并。

现有 `kinetics.py` 已明确只接受单分子活化自由能；应保持这个契约。电子能启发式另放独立评分模块。若暂用 DeltaE 代替 DeltaG、统一前因子运行近似动力学，应单独标成代理模型并做温度/势垒误差敏感性，不输出可信实验产率。

小型已知单分子网络直接解速率矩阵通常比 KMC 更简单。KMC/Gillespie 用于有明确速率/倾向函数的动力学轨迹；MCTS 用于分配探索计算预算。两者可联合，但物理意义不同。多分子体系需要浓度、化学计量、标准态和质量作用动力学，不能复用上述简单 Q 而不作改变。

### 最终产物与终止

产品应是给定时间窗口内积累的物种或产物集合，允许不反应、混合产物及后续转化。当前无已知出边的节点可能只是未探索边界，不能自动当作稳定终产物。

算法终止可按总力评估/墙钟/DFT预算、连续若干轮主要候选和通量稳定、重要边界覆盖及保留的探索预算共同决定。停止后报告剩余前沿与证据缺口，不宣称唯一完整机理。

完整机理输出为主要通量子网络及代表路径，保留竞争通道和催化回路，而不是只返回 MCTS 的一条获胜分支。

本轮实际审计当前受限提供器：67 条回放通过的源记录，123 个图节点、127 条可执行有向图边、57 个弱连通分量；最大分量 5 个节点。它只描述当前过滤/精确匹配实现，不代表整个 SynEPD 或全部符号化学空间。详见 `reports/symbol_search_space_audit.json`。

因此，不能直接在当前两三节点的循环上宣称验证了长期 MCTS 优势。需要先建立可迁移局部动作，再选择有多分支、至少数步竞争路径的体系。

数据表可先用 SQLite：states、symbol_actions、attempts、events、energy_estimates，加搜索统计。结构/轨迹放独立文件，数据库保留哈希与路径。用唯一任务键避免并行重复计算；不同方法、模型版本和环境不可共用物理缓存。

## 9. 模型与多保真策略

初版继续使用已接入的 AIMNet2-rxn；适用域为净中性闭壳层 CHNO，不能把局部形式电荷或新碎片生成视作适用域保证。[作者模型卡](https://huggingface.co/isayevlab/aimnet2-rxn)

- 便宜层：符号合法性、几何可行性、短松弛与少量势调用。
- 中间层：完整 MLIP 鞍点与连接验证、多个种子、必要的模型成员分歧。
- 高证据层：重要通道、产品排序敏感边、异常电荷分离及不确定区域的 DFT/IRC。

集成分歧需要校准，成员一致也可能共同错。域外/高不确定候选送去复核，不应因预测势垒异常低而无限扩展。DFT 改连时新增/链接真实事件，保留原模型记录并使受影响评分失效。

当前 DFT 标准与势模型训练参考不同。可以据连接结果训练提议可靠性或兼容性模型；若微调势函数，需统一参考方法或显式建模不同理论层级，不能直接混合绝对能量和力。

## 10. 对当前代码的具体增量

| 现有部分 | 改动 |
|---|---|
| symbolic_library.py | 全体系匹配之外增加局部模式实例化、守恒动作枚举和表示等价处理；审计芳香/反向回放 |
| search_seeds.py | 多构象、供受体接近方向、异步扫描；保留同幅度对照 |
| reaction_network.py | 抽出可复用的“执行一次 action/seed”接口，BFS 与 MCTS 共用同一个物理求解器 |
| 新 search_policy 模块 | PUCT、渐进扩展、路径上下文、缓存统计、失效更新；先不用神经价值函数 |
| 新 path_scoring 模块 | 电子能启发式与真实自由能速率分开 |
| kinetics.py | 复用现有单分子自由能速率矩阵；后续再接多分子动力学 |
| verification.py / QC 脚本 | 重要事件队列、保留改连与未解决，按证据等级回写 |
| 现有可视化 | 同时展示动作提议、实际网络、边证据与主要通量路径 |

缓存层首先解决相同动作/种子/求解设置重复求解；提议对称性去重后仍保留不同 TS 和构象实例。异步计算要限制同一树分支并行提交量，避免多个 worker 重复追逐一个候选。

还需区分两类缓存：极小值身份可用几何容差去重；能量/力缓存应对应同一精确几何与同一计算设置，不能用粗坐标舍入替代。比较调度器时，使用由稳定状态 ID、动作 ID 和种子 ID 决定的随机数，避免节点发现顺序改变几何采样。各算法保留独立知识视图；若复用共同的物理计算档案，必须按原始任务成本统一记账，不能让后运行的算法免费获得前一个算法已算出的网络。

## 11. 建议的实施顺序与验收

### A. 有限动作生成器

在 10–20 个明确声明的起点上测量：合法动作数、不同净变键/箭头分解数、实例化时间、未知中心覆盖、是否产生纯共振或未配平动作。先证明动作覆盖能支持多步分支。

### B. 冻结网络上的调度验证

从已有验证事件构成若干小型参考网络；模拟逐条揭示事件，比较 BFS、随机、能垒贪心、优先队列、MCTS。记录更快找关键路径与漏支的情况。这只是调度单元基准，不能替代在线 TS 搜索验证。

### C. 在线真实搜索

使用同一个动作池、同一个种子生成器、同一个 MLIP 和相同总计算预算，仅改变调度器。建议每体系至少 3–5 个随机重复；选择确有多步和分支的体系，而非仅一个互变异构对。

主要指标：DFT 抽查支持的根连通事件/成本、重要路径覆盖、产品排序随预算的稳定性。另报全部 MLIP 候选、重复率、意外连接、假低势垒、未解决、符号无覆盖和域外比例。参考网络自身也不当作全部反应空间的真值。

### D. 物理证据反馈

比较随机 DFT 抽查、按低势垒抽查、按产品排序敏感度/不确定性抽查。固定测试体系；观察修正后产品排序和重要路径是否更稳定。增加数据量本身不叫反馈学习成功。

### E. 后续学习

积累实际 action→seed→event 数据后，再训练三维种子策略、动作先验或价值模型。可模仿搜索访问分布，但它表示计算分配策略，不表示反应速率。强化学习的奖励仍需由明确物理目标定义；闭环更新必须在独立体系上验收。

## 12. 总体判断

工程可行性较高：现有项目已具备动作回放、种子、MLIP、鞍点/下降、实际事件注册、DFT 复核和可视化。近期最重要的缺口是动作可迁移覆盖、带缓存与回路处理的调度、以及条件化产品评价。

科学可行性需分开看：符号方向帮助局部搜索已有小样本证据；完整箭头比净变键更有效尚未得到充分物理支持；MCTS 是否比简单优先队列更省计算尚未测试；自动预测完整实验机理与产物分布尚未证明。

建议第一项完整目标：在限定化学域内，从不指定目标产物的起点出发，以局部电子动作引导并逐步建立经验证事件网络，在相同预算下证明 MCTS 的调度增益，并公开每条候选的符号与物理证据。它可以在训练强化学习模型之前完成。
