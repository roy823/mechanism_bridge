# 基于“弯箭头 × 鞍点”深查报告的研究重评

日期：2026-09-29。输入为用户提供的《文献深查-弯箭头x鞍点-2026-09-29.md》，结合本项目 `FEASIBILITY_RESULTS_zh.md`。本轮重新核对了关键论文摘要、作者代码和模型卡，没有逐条复核输入报告全部文献、统计和许可判断，也没有开展新计算。

## 1. 更新后的判断

课题有可检验的科学基础；目前尚未证明可靠的自动箭头配对或双向闭环收益。优先研究的问题是：在明确的电子态、环境和理论层级下，能否把经验证的三维基元事件转成稳定、可回放、允许多解的电子对重排解释；这种解释是否提供超出端点净变键的信息，并帮助搜索正确连接的 TS。

“两个现有模型加物理计算”的组合可以用作实现框架。贡献需要落实到事件对应算法、独立审核的配对数据和可重复的搜索收益。随机森林保留为已完成的基线。

## 2. 文献如何改变定位

- **闭环有明确先例。** Sadowski et al. 2016 的摘要明确包含电子源—汇排序、TS/活化能计算、再训练。本项目不能主张首次把机理预测与量化反馈结合。[原文摘要](https://pubs.acs.org/doi/10.1021/acs.jcim.6b00351)
- **IRC 到图电子流已有实现。** OpenDIGR 作者仓库提供 xTB TS/IRC、YARP 键电子矩阵、桑基图和分类流程。应加入比较对象。它的图电子流与波函数响应证据的差别需要用实验体现。[作者流程](https://github.com/Savoie-Research-Group/OpenDIGR/blob/main/plugin/README.md)
- **TS 局部电子响应已有方法。** NRO-at-TS 摘要报告沿虚频模的占据—虚轨道响应及与周环反应箭头的对应。它支持反向任务的物理基础，但没有因此给出通用的、已经验证的机器箭头解码器。本轮没有取得并复现该论文完整实现。[作者摘要](https://pubmed.ncbi.nlm.nih.gov/42708651/)
- **正确连接比局部鞍点更有区分度。** TSBench 报告很多失败候选连接错误端点，可用于支持采用连接成功率作为指标；不能直接外推其失败比例到我们的反应分布。[预印本](https://arxiv.org/abs/2609.08503)

建议论文定位：面向经验证基元事件的、电子结构证据约束的符号机理推断与双向搜索。对“首次”使用有范围、有截止日期的检索表述。

## 3. 输入报告需要收紧的结论

1. 引文交集为零、没有查到基金或专利，都不能证明全球没有已有实现；也不能推测别的团队距离完成仅差一步。
2. “没有人自动输出机器箭头”范围过宽，报告自身也列出二维箭头模型。需要限定为从三维电子结构证据自动解码、具有明确电子位点语义且做过独立验证的箭头。
3. 精确交集小只否定批量连接两个现有库的捷径。已有物理事件仍可补电子结构和箭头，已有符号事件则可补三维搜索；不需要所有 TS 都从头算。输入报告的交集上界缺少本项目可复现的脚本、版本和筛选记录，暂不作为确定统计引用。
4. 弯箭头是离散解释，电子密度响应是连续量。不能把每支箭头当成唯一可观测的电子轨迹；NRO 权重也不能直接当成整数两电子转移量。优先保留候选集合、证据和解释约定。
5. 箭头书写顺序不是反应时间；IRC 参数也不是动力学时间。沿路径某信号先变化不等于存在额外中间体。拆分步骤需发现并验证中间极小值及相邻连接。
6. 对固定线性问题，最小欧氏范数的最小二乘解是唯一的。输入报告“最小范数解不唯一”数学措辞不准确；物理源—汇分解的歧义来自表示选择、约束及环流自由度等，不能混为一谈。
7. 多种电子分析同意是有用特征，但不能直接作为校准后的正确概率。它们可能共享同一波函数误差和 Lewis 表示偏差，仍需独立审核和稳定性测试。
8. 未找到 TS 不证明符号步骤错误；发现另一鞍点不证明原事件不存在；多个构象 TS 也不等于多个符号步骤。SN2 等反应可能有前后络合物，需预先定义是否将缔合/解离纳入步骤计数。
9. 不直接把 ALPB 作为任意 MLIP 的通用附加项；总能量、电子电荷响应及一致的力需要明确实现和验证。离子/溶剂问题单列后续适用域研究。
10. SynEPD 数量有版本差异：本轮公开 v0.4.0 页面列 1,926 个反应、8,123 根箭头，输入报告为 8,129。入库以固定版本和 manifest 为准。[作者发布说明](https://pypi.org/project/synepd/0.4.0/)

## 4. 两种数据背后的联系

符号侧描述原子/键/孤对位点的形式电子对重排；物理侧描述指定势能面上的核路径及电子态响应。共同索引为原子身份、完整体系、电荷/自旋和实际连接事件。

推荐记录分为三层：

- **物理事实层：** 理论层级、环境、TS、虚频模、两侧路径、优化端点及验证状态。
- **电子证据层：** 局部响应、轨道/密度/键级的路径变化、数值稳定性和不确定项。
- **符号解释层：** 可回放箭头集合、等价约定、专家判断与原始来源。

同一端点图对可包含多个构象路径实例；每个实例可有多个相容解释。图对 ID 用于分组，不能替代路径实例 ID。带电或溶剂辅助反应还必须记录显式参与物，避免原子/质子不守恒的伪配对。

## 5. 数据与模型优先级

| 资源 | 用途 | 入库/接入条件 |
|---|---|---|
| 本项目 4 个 DFT 验证事件 | 算法回归与歧义诊断 | 不作独立泛化测试，也不作人工真值 |
| SynEPD | 教科书箭头参考、可执行表示 | 固定发布版本；确认完整体系、步骤粒度；无需预设与物理库重合 |
| MDCD-NN 教科书集 | 更有化学解释性的 TS 候选 | 作者仓库列 100 中性和 81 自由基反应；首轮筛选适合闭壳层方法的子集，逐条核对 DFT 文件与 IRC 证据 |
| Reaction-QM 子集 | 已有 DFT IRC 的物理事件来源 | 先查元数据与可获取子集；已有轨迹不等于已有波函数，需补电子结构单点 |
| OpenDIGR / GDB 路径数据 | 方法比较和后续扩展候选 | 核对理论层级、轨迹完整性和自旋，不先整库追加下载 |
| FlowER / mech-USPTO | 规模化符号先验 | 单独标记模板来源，避免当作独立物理真值 |

Reaction-QM 原文报告 199,890 个 DFT 反应及完整 IRC 轨迹，适合补电子证据。[原文](https://www.nature.com/articles/s41597-026-07325-w_reference.pdf) MDCD-NN 的实际数据目录、计算类型与格式见[作者仓库](https://github.com/RA-zoL/MDCD-NN)。

模型接入建议：

1. **AIMNet2-rxn：** 在 CHNO、净中性闭壳层范围内提供搜索能量和力。它不输出 NRO/IBO 所需波函数；局部形式电荷不等于体系净电荷，净中性也不自动证明离子对适用。[模型卡](https://huggingface.co/isayevlab/aimnet2-rxn)
2. **PySCF 电子响应/NRO + 现有 IBO：** 作为逆向算法的证据生成器。正式实现按响应方程处理运动基组，不能用原始 AO 密度矩阵直接相减冒充 NRO。
3. **RitS 或 React-OT：** 按是否已有端点三维构象选一个作为 TS 生成基线。两者默认输入都没有完整箭头，因此仅把箭头化成 R/P 再调用，不能证明箭头特有信息有益。[RitS](https://github.com/isayevlab/RitS)、[React-OT](https://github.com/deepprinciple/react-ot)
4. **FlowER：** 后续作为电子重排提议器/先验；反向事件解码仍需新算法。先保持模型冻结，待可信配对积累后训练条件模块或做适配。[作者仓库](https://github.com/FongMunHong/FlowER)

## 6. 下一轮应直接检验的假设

以下数量为研究设计建议，不是完成数量或统计功效保证。

### A. 先证明箭头解释可以稳定获得

先用已有 4 个事件排查表示问题，再预先选择约 20–30 个事件，覆盖质子转移、键裂解/形成和周环等适合方法的类别。方法开发与审核测试分开；审核者能拒绝或保留多解。

比较：端点图；端点图 + TS 几何；再加虚频模；再加电子响应和必要的路径证据。另设 IBO 单独、局部 NRO、沿路径多信号对照。

指标包括：箭头源—汇精确率/召回率、可接受解释集合命中率、回放一致性、旋转/重编号/局域化扰动稳定性、拒答覆盖率。电子对守恒只算合法性检查。对端点几乎决定答案的例子，不能声称电子结构提供了新信息；优先分析存在多种源—汇分解的事件。

### B. 再证明符号信息帮助物理搜索

固定同一个生成模型、MLIP、DFT 验证层级及计算预算。比较 R/P 条件、加入净变键、加入完整箭头约束/候选评分三种输入。真正增加的条件模块应利用源—汇、涉及位点或协同关系，而非只重复产品图。

统计最终同层级端点连接成功率、每个正确事件的量化成本、替代有效事件产出。预训练覆盖要审计；正逆方向、构象和同一事件不能分到训练与测试两侧。

### C. 最后证明反馈有用

冻结独立测试集，在相同新增量化预算下比较随机采样、势模型不确定性、符号—物理分歧驱动采样。分别报告配对标签修订与模型参数更新；数据新增不等于性能改进。

若 A 失败，优先研究稳定表征；若 A 成功但 B 无提升，可形成电子证据配对/解释研究，并继续检验正向条件设计；若 C 无提升，保留负结果，不把闭环画出来就算完成。

## 7. 当前项目离这些目标还有多远

本项目已有 4 个通过指定 DFT 连接验证的事件，尚无独立审核箭头对。刚体变换导致一个事件原始箭头 4→2，说明自动标签不能直接大规模训练；一次极小样本反馈探针的误差由 0.1266 增至 0.1486 Å，没有成功更新证据。现有结果支持继续开发事件验证与解释算法，不能支持“完整双向学习已可行”的结论。

下一项最有价值的交付：固定版本的符号参考数据 + 一小组可审核物理事件 + 稳定性可测的 TS/路径到箭头集合解码器。在这个基础上接入预训练 TS 模型和 MLIP，测试符号引导的增益。模型融合保留为后续阶段。
