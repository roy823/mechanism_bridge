# FP-JCTC-2：孤对电子项的修正与验证计划（草案，2026-10-05，待用户过目）

用户已同意先修正、再在留出数据上验证（10-05"全部同意"）。本草案在开跑前写定。凡是看过结果之后才定的内容，都会另行标注。

## 1. 要修正的问题
证据见结果记录 §11：
- 同一提案、同一随机数下，孤对电子方向项生效时，箭头种子到达预测产物的次数是 290 对 bond_edits 387（p = 1×10⁻⁷）；
- 不生效时两者打平，箭头还略好；
- 箭头反向或打乱之所以"更好"，是因为关掉了这一项；
- 箭头信息本身在几何上是对的：T1x 上箭头种子更接近参考 TS（10/13）。

## 2. 候选修正（开跑前固定，最多 3 个）
- **V1：去掉全部孤对电子项**，包括种子拟合里的方向残差和相遇取向打分。其余箭头特征（推拉顺序、相邻箭头耦合）保留。这是最简单、最不容易过拟合的方案。
- **V2：保留方向项，但改成弱约束，并保持键角。**
  - 残差权重从 ÷0.3 降到 ÷1.0；
  - 对供体原子上已有的键角加保持项，形式与未变键长的保持项相同；
  - 相遇取向打分不变。
- **V3：方向项只用于分子间进攻**（双分子相遇中供体与受体分属不同分子），分子内的氢迁移等不加。理由：分子内过渡态是张力环，VSEPR 的孤对电子方向并不适用。这一点是我的判断，未验证。

对照组：FP-JCTC-1 的 arrows（V0）与 bond_edits。

## 3. 开发阶段：在已分析过的数据上选定变体
- **新工具（种子重放）**：
  - 对抽中的尝试，用原节点几何、原提案、原随机数，在每个变体下重新构造种子；
  - 再用冻结的 TS 阶段（Dimer → Sella → Hessian → IRC）跑一次；
  - 按尝试成对比较结果。
- **样本**：从 C1、C2、C3、C6 中按战役等量抽取孤对电子项生效的尝试，共 240 个（种子 20261005）；另抽 120 个不生效的作检查，变体不应改变它们的结果。
- **指标**：到达预测产物（主）、IRC 连通（次）、每次尝试的评估数。
- **选择规则**（开跑前写定）：
  - 在 V1–V3 中选到达预测产物比例最高的变体；若相差不到 2 个百分点，就选更简单的（V1 > V3 > V2）；
  - 选出的变体要至少不劣于 bond_edits（非劣界 −2 个百分点）。如果做不到，确认阶段就用 V1，并如实报告"箭头种子细节没有带来增益"。
- **计算量**：约 360 × 5 次重放，大约几十个 CPU 小时，用 burst 跑。

## 4. 确认阶段：在留出数据上检验（开跑前写定）
- **留出数据**（都不与已用数据重叠）：
  - Coley：从 1242 条合格反应中，排除已用的 100 条，按原分层再抽 100 条（种子 20261005）；
  - RGD1：同样排除已用的 100 条，再抽 100 条；
  - T1x：用官方 val 分割中可表示的反应（val 数据是否已在 UF 上待核实）；
  - 效率集：另选 10 个未用过的 C2–C4 含氧小分子，开跑前列出名单。
- **策略**：
  - arrows（FP-JCTC-2，选定的变体）；
  - bond_edits；
  - center_random；
  - geometry；
  - 新增 **enumerated_edits**：同一引擎，但提案换成不含箭头的随机变键枚举（"断 ≤2、成 ≤2"，加价态上限），种子按 bond_edits 方式构造。它用来检验"箭头模板作为提案来源"的价值。
- 每种策略 10 个种子。
- **主要假设与检验**（两个主要假设之间做 Holm 校正）：
  - H1：arrows（FP-JCTC-2）的 S1 找回率不低于 bond_edits；效率指标同图 3；
  - H2：bond_edits（模板提案）的找回率和效率高于 enumerated_edits（不含箭头的提案）；
  - 检验口径同 FP-JCTC-1：体系配对 Wilcoxon、按起点聚类自助区间、训练重合分层、根保持敏感性分析。
- **计算量**：与主战役相当（约 1–1.5 万个运行），用 burst 跑。
