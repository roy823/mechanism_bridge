# 潜空间动力学与 TransitionNet：调研与设想（2026-10-05）

## 1. 图里的想法
- 图中三个阶段：
  - Stage 1：性质预测；
  - Stage 2：结构生成；
  - Stage 3：潜空间动力学，即分子是潜在表示空间（流形）上的点，能量是流形上的曲面，反应是曲面上的轨迹（例：苯甲醇 → 苯甲醛 → 苯甲酸）。
- 图的出处（"Wave Intelligence"）没有检索到，需要向同学确认。

## 2. 相关工作（摘要取自原文，2026-10-05 查阅）
- **LatentRxnFlow**（arXiv 2602.10476，KDD 2026）：
  - 输入反应物图（及条件），输出产物图，在潜空间里用 flow matching 学一个随时间变化的向量场；
  - 训练只用 USPTO 的反应物–产物对，没有 TS、能量或机理；
  - 作者承认潜轨迹不对应物理的反应坐标，也可能偏离合理机理。
- **Molecular latent space simulators**（Chem. Sci. 2020）：从 MD 轨迹学习慢变量和潜空间动力学，再生成原子构型；用于构象和折叠动力学。
- **From latent dynamics to meaningful representations**（JCTC 2024）：约束潜表示服从带可学习转移密度的过阻尼 Langevin 动力学。
- **ReactionAtlas**（arXiv 2606.30778）：
  - 用扩散模型（MoreRed）提出 TS，用力场验证；
  - 按稳态动力学选择下一步展开的化合物；
  - 只有气相，元素限于 C/H/O。
- **空白**：还没有工作同时用"物理验证过的反应路径（TS、IRC、能量）"和"机理注释（箭头）"来学潜空间动力学。

## 3. 本项目已有的数据正好对应这个空白
- 每个已验证的边都保存了：
  - 双向 IRC 轨迹（每一帧的几何和能量）；
  - TS 频率、两端极小、势垒；
  - 对应提案的箭头和净变键。
- 失败的尝试也记录了类型（TS 不收敛、IRC 未连通等），可以作为"这次没有连通"的弱负样本。注意：失败不等于反应不存在。
- 规模：
  - 盲搜战役里约 3.8 万条已验证的化学边（去重前）；
  - 还有给定反应中心和消融战役；
  - DFT 复核的 80 条可以作为物理标签。

## 4. 设想的模型（TransitionNet 里负责"判断"的部分）
- **编码器**：把反应中心的局部几何映射为潜向量。可以先直接用 MLIP 内部的原子环境特征。
- **潜能量曲面**：潜空间上的能量函数，在 IRC 帧上拟合 MLIP 能量。
- **潜动力学**：一个向量场，以箭头或变键为"控制信号"，以温度、溶剂、pH 为条件参数。训练目标是让 IRC 路径成为潜空间里的光滑轨迹。
- **用途**：
  1. 筛选：对符号提案预测能否连通、能否到达预测产物、势垒多高，只把可行的提案交给昂贵的 TS 搜索，用来加速建网；
  2. 条件依赖：在溶剂或 pH 校正过的能量上微调，判断给定条件下哪些边可达；
  3. 解释：把网络（formose、糖酵解）画成潜空间能量地形上的路径，对应图中的 Stage 3。

## 5. 先做的小实验（不需要新的大规模计算）
1. **导出数据集**：从现有战役抽取已验证边的 IRC 帧（降采样）、能量、箭头和变键，以及失败的尝试。
2. **可视化检验**：用 MLIP 特征加降维，检查三件事：
   - IRC 路径在潜空间里是不是光滑曲线；
   - 能量是否随路径平滑变化；
   - 成功和失败的提案能否分开。
3. **基线**：用一个简单的分类器预测"这个提案能否连通"，和"直接跑 TS 搜索"的结果比较，看能省下多少计算。

如果第 2、3 步有信号，再训练带条件的潜流模型。

## 6. 风险
- 潜空间能否跨化学体系泛化：训练数据只覆盖 CHNO 小分子。
- 失败样本不是真正的"不可达"，标签有噪声。
- 糖酵解需要含磷物种、带电物种和溶剂（见 §7）。

## 7. 糖酵解所需的势能模型（10-05 核查）
- 本项目所用的 aimnet2-rxn 只支持 H、C、N、O（`src/mechbridge/potentials.py`），无法处理磷酸。
- 代码里已接入通用 AIMNet2（aimnetcentral）：
  - 支持更多元素和带电体系，具体元素在本环境中待核实；
  - 但不是为反应 TS 区域训练的，需要先在含磷反应的 DFT TS 上验证。
- 溶剂：先用 DFT 隐式溶剂单点校正能垒，或在体系中加显式水分子。
