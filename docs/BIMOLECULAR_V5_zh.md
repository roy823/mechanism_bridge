# 从重排扩展到双分子反应

## 研究问题

在只提供反应物的条件下，电子动作与相对取向能否引导机器学习势找到真正跨分子成键的鞍点？
本轮扩大动作与几何的覆盖范围，沿用严格的实际端点登记和独立 DFT 复核。

## 文献与数据

- [ReactionAtlas](https://arxiv.org/html/2606.30778v1)：参考甲醛、水、小糖体系，以及双分子相遇取向采样。我们的六组试验不是其完整网络复现。
- [Stuyver、Jorner、Coley 的双分子环加成数据](https://github.com/coleygroup/dipolar_cycloaddition_dataset)：下载作者数据表，固定提交 `1608a64499779bf8f89a886308d97c6a830d084c`；记录 3217、3216 分别有 14、15 个显式原子。选择依据为原子数与 ID，未按能垒或成功结果选例。
- [Jin/Coley 强化学习论文](https://hdl.handle.net/1721.1/151666)：案例是自由基氧化和自由基串联环化；这轮只借鉴电子动作表述，不运行超出闭壳层模型范围的自由基体系。

下载的表包含参考产物和水相自由能。起点文件只输出反应物三维坐标与来源；搜索不读取参考产物、参考 TS、参考能垒。单独的 `coley_held_out_reference.json` 只供事后对照。
这里的 held out 仅表示没有提供给本次搜索，不表示这些化学类型从未出现在预训练模型的数据中。

## 实现

1. SynEPD 源记录允许一或两个反应物，仍检查中性 CHNO、电子对来源、价态、电荷守恒与回放结果。当前得到 210 条可回放记录、351 个正反方向局部模板。
2. 对文献库未覆盖的双分子情形，加入四种**人为指定、显式标注**的电子动作模式：带质子转移的羰基加成、中性烯醇 aldol 加成、羰基 C–H 耦合加成假设、1,3-偶极环加成。规则通过当前反应物子结构匹配构造箭头，产物图由回放推导；不是已训练模型，也不是穷举所有电子动作。
3. 独立嵌入每个反应物并做 UFF 优化，随机刚体旋转，按 vdW 间隙 0.2 Å 组装两个分子。每组保留两个随机取向，先进行无约束 MLIP 极小值检查。
4. 符号 seed 额外尝试 64 个刚体取向，以拟形成的跨分子键距离和原子碰撞作为几何评分；不调用 PES、不使用参考产物。之后进行距离、角度和电子源/受体耦合拟合，再在真实势能面搜索。
5. 对所有模板先收集再按产物假设轮转截断，避免一个对称等价家族占满 24 个候选。仍有每模板 64 个匹配和每节点 24 个提议的上限，不声称完备。
6. 实际端点按跨片段重原子成键、跨片段氢转移、带旁观物的单分子重排、构象/共振表示分别分类。枚举共振式仅用于已证实的表示等价；不以此合并不同几何盆地。

符号组的刚体取向变化单独记录，不能把其全部位移说成与几何对照相同。0.6/1.0/1.4 Å 只约束后续内部形变的范数。本轮比较的是整个符号引导方案，不是隔离完整箭头信息的消融。

## 单独的事后诊断

作者的结构档案约 94 MB，已按固定 Git blob 与 SHA256 核验。两个例子的原始 TS 与虚频位移仅用于独立的参考 seed 诊断，不计入反应物起始命中率：

```powershell
.venv-explore\Scripts\python.exe scripts/data/fetch_coley_dipolar.py --reference-profiles
.venv-explore\Scripts\python.exe scripts/diagnostics/check_coley_reference_ts.py --outdir reports/new_oracle --fmax .001
.venv-explore\Scripts\python.exe scripts/diagnostics/diagnose_encounter_minima.py --outdir reports/new_encounter_check
```

原始参考 TS 诊断使用 0.005 eV/Å，两个例子均保留目标图对，但各有一个末端存在约 −70 cm⁻¹ 负曲率。单独重跑至 0.001 eV/Å 后，3217 通过完整 MLIP 双端检查；3216 的产物优化仍未收敛。不能把参考 TS 诊断称为自主发现或 DFT 验证。

相遇构型诊断先尝试 BFGSLineSearch/0.0005 eV/Å，但五组均未同时完成两个端点的验收，不能据此判断盆地是否相同。随后独立采用项目原有 BFGS/0.001 eV/Å，五组的两个端点都通过极小值检查，但仍是不同几何盆地。全部原始负结果保留，主网络不追溯合并。

甲醛二聚的补充 DFT 是看到 MLIP 结果后选取的 C–C 成键诊断。首次优化虽报告停止，最终真实力 0.02028 eV/Å 略高于 0.020 验收门槛；更严格停止条件的精修另存，不覆盖原始失败记录。
当前代码将后续 DFT TS 的默认优化停止目标设为 0.010 eV/Å，最终真实力验收仍为 0.020；每次运行会记录两者。原始实验以各自保存的源代码为准。

## 尚未解决的边界

本轮主实验已完成 36 组计划运行、250 次尝试、302414 个几何评估，主搜索墙钟 20.6 分钟（不含独立 DFT）。跨分子重原子事件数为 geometry 0、arrows 8、hybrid 7；跨取向和策略去重为 6 个化学图对。

独立气相 ωB97X/6-31G(d) 检查确认甲醛 + 水 ↔ 甲二醇，以及经单独严格精修的两分子甲醛 ↔ 羟基乙醛。正向电子能垒分别为 1.5317、3.8329 eV，参照各自实际相遇极小值；二聚高能垒不支持常温快速反应的结论。两者均为 1 个 TS 显著虚频、两端 0 个显著虚频且双向 IRC 完成。

代码检查：Windows 45 项通过、1 项 PySCF 跳过；WSL 46 项通过。主实验 442 项记录检查、补充实验 105 项检查和原始 DFT 6 项源代码校验均通过。

- 同一对分子的不同相遇构型可以属于不同极小值。匹配反应物分子图不等于已连接初始复合物；严格根连通单独统计。
- 每个子网络仍固定原子库存。这里没有动态补充第三个分子或自动的多化学计量反应物池。
- MLIP 下降不是 IRC，电子能垒不是活化自由能。不能把气相结果直接当作溶液速率、产率或与 Coley 水相自由能的误差。
- 规则提供的箭头只是物理搜索的提议来源。TS 与双侧端点验证本身不能证明唯一电子机理。

## 由本轮证据支持的下一层实现

需要区分“相同反应物库存”和“相同三维极小值”。A+B 的多个相遇极小值可以分别成为探索起点；每条 TS 仍只连接它实际到达的两个极小值。物种及化学计量层可以汇总这些事件，三维盆地层保留各自身份及未证实的连通关系。

因此下一层应让已验证事件的新端点进入独立探索队列，并显式处理相遇构象转换与反应物重新组合。对无势垒的接近/分离过程需要独立判据，不强行虚构一个一阶鞍点。不要把当前“单个初始相遇盆地的根连通数为零”误读为没有找到 A+B 的真实反应。

环加成方面，3217 的参考 seed 对照给出了明确目标：改进反应物相对取向、多键协同方向与形变采样，或引入已有三维 TS 提议模型；保留当前势能验证接口，并以反应物起始命中率检验改进。3216 的端点收敛问题需要先单独排查，不能把所有失败都归因于 seed。
